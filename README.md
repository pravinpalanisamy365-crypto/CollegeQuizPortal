# College Quiz Portal

A web-based quiz portal developed for conducting college quizzes online.

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- Node.js
- Express.js

## ✨ Features

- Student login
- Google/Gmail authentication
- Quiz topic selection
- Multiple-choice questions
- Score calculation
- Student email verification

## 🚀 How to Run

1. Clone the repository.
2. Install the required packages:
   npm install
3. Start the server:
   node server.js
4. Open:
   http://localhost:3000
